# YouTube to Gemini Ext
YouTubeの動画ページから、Geminiに動画概要の作成を依頼するChrome拡張機能です。

## 使い方
1. このリポジトリをダウンロード（CodeボタンからDownload ZIP）します。
2. Chromeの拡張機能管理ページ (`chrome://extensions/`) を開きます。
3. 右上の「デベロッパーモード」をONにします。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、解凍したフォルダを選択します。

## 機能
- YouTube動画のリンクを右クリックして、自動的にGeminiへ概要作成を依頼します。
- 動画リンク上で右クリックし（Geminiで概要を作成）を選択で機能します。
- ページ内に埋め込まれたYouTube動画にも対応しています。
- 対象となるリンクはYouTubeの各種お勧めなどです。他ページの埋め込みだと機能しない場合があります。

## 効能

- 目を引いたけれども見るまでも無い様な動画の概要を手軽に取得できます。興味があれば動画視聴に移行すれば良し、そうでなければそれなりに。ゴミ動画で履歴やおすすめが汚染されなくなるので宜しいかと思います。

## その他

- Gemini側がへそ曲げていると情報取得に失敗します。リトライシーケンスを組んでいますが駄目な時は駄目なんで諦めましょう。
- YouTubeやGeminiの更新などがあると機能しなくなると思います。その場合はソースをGeminiに投げつけて何とかしてもらってください()
